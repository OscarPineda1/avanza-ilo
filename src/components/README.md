Componentes de interfaz reutilizables.

- Base: `AppButton`, `ScreenHeader` y `EmptyState`.
- Rutas: `RouteBadge` y `RouteListItem`.
- Componentes de dominio: tarjetas de ruta, mapa, navegación inferior, ajustes y conectividad.

Una pantalla no debe recrear estos patrones: compón los componentes existentes y agrega aquí cualquier patrón que se use en más de una pantalla.
